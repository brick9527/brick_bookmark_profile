# 权限用途说明

**适用于**：BrickBookmark（书签管理器浏览器扩展，下称"本扩展"）
**对应隐私政策版本**：v1.0.0（2026 年 11 月 11 日）
**说明**：本文件为隐私政策附件，独立说明本扩展所申请的各项浏览器权限及其用途，与隐私政策正文配套使用。

## Chromium 系浏览器（Chrome / Edge）

| 权限                      | 用途                                                                                                                                                |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bookmarks`             | 读写用户书签，实现书签管理的核心功能                                                                                                                                |
| `storage`               | 在本地保存置顶、标签、备注、设置等扩展数据                                                                                                                             |
| `sidePanel`             | 提供侧边栏界面，不离开当前页面即可访问书签                                                                                                                             |
| `tabs`                  | 打开用户点击的书签链接（前台 / 后台）                                                                                                                              |
| `favicon`               | 在书签列表中显示网站图标                                                                                                                                      |
| `search`                | 仅用于新标签页搜索框：当关键词既不是书签、也不是网址时，转交浏览器设置的默认搜索引擎处理；本扩展不接收、不记录、不上传该关键词 |
| 与服务器通信（brick9527.qd.je） | 实现账号登录、反馈提交等在线功能（服务器地址由开发者打包配置）                                                                                                                   |
| 按需的网站访问权限（可选权限）         | 仅用于用户主动触发的链接校验与标题刷新；作为可选权限，授予范围仅为用户实际校验 / 刷新的书签域名，由用户在首次使用对应功能时按需授予，授予前不访问任何网站，后台也不会自动访问任何网站。用户可在浏览器扩展详情页的"网站访问权限"中查看并随时取消任一已授权网站；链接校验页会显示已授权网站数量 |

本扩展仅申请实现上述功能所必需的权限，不申请任何超出功能需求的权限。

> Chromium 版另通过 manifest 的 `chrome_url_overrides.newtab` 用新标签页仪表盘替换默认新标签页；该字段属于页面替换声明，不涉及任何额外权限，仪表盘展示的数据全部来自本机已有的书签与访问统计。

## Firefox

| 权限 | 用途 |
|---|---|
| `bookmarks` | 读写用户书签，实现书签管理的核心功能 |
| `storage` | 在本地保存置顶、标签、备注、设置等扩展数据 |
| `sidePanel` / 侧边栏 | 提供侧边栏界面，不离开当前页面即可访问书签 |
| `tabs` | 打开用户点击的书签链接（前台 / 后台） |
| `favicon` | 在书签列表中显示网站图标 |
| 与服务器通信（brick9527.qd.je） | 实现账号登录、反馈提交等在线功能（服务器地址由开发者打包配置） |
| 按需的网站访问权限（可选权限） | 仅用于用户主动触发的链接校验与标题刷新；作为可选权限，授予范围仅为用户实际校验 / 刷新的书签域名，由用户在首次使用对应功能时按需授予，授予前不访问任何网站，后台也不会自动访问任何网站。用户可在浏览器扩展详情页的"网站访问权限"中查看并随时取消任一已授权网站；链接校验页会显示已授权网站数量 |

本扩展仅申请实现上述功能所必需的权限，不申请任何超出功能需求的权限。在 Firefox 中，本扩展依据 Firefox 内置的数据收集同意机制，仅在获得用户同意后传输可选数据（账号、反馈、技术数据）。

Firefox 版不打包新标签页仪表盘，因此**不声明 `search` 权限**，也不声明新标签页页面替换。
