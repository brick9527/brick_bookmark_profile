# 隐私政策

**适用于**：BrickBookmark（书签管理器浏览器扩展，下称"本扩展"）
**发布日期**：2026 年 11 月 27 日
**生效日期**：2026 年 11 月 27 日
**当前版本**：v1.1.0（上一版本 v1.0.0，2026 年 11 月 11 日）

## 概述

本扩展是面向各类浏览器的书签管理工具，**默认在本地运行，基础功能不收集、不存储、不上传任何个人数据**。

仅在用户**主动启用服务器功能**时，才会将必要的账号信息与反馈内容发送至**由开发者运营的公共服务器**。除服务器功能、三方登录与用户主动触发的网络请求外，本扩展不进行其他网络通信，不包含广告和追踪组件。

本版（v1.1.0）新增或变更的数据处理行为如下，均在本政策中逐项披露：

- **三方登录与账号绑定**（GitHub / Google / X）：由浏览器打开来源方授权页，本扩展只把授权码交给服务器换取登录态，`client_secret` 只存服务器、不进扩展包。每个平台使用各自登记的 OAuth 客户端与回调地址，入口是否显示以服务器 `GET /auth/oauth/capabilities` 返回的白名单为准。**Edge 版在扩展 ID 与独立 OAuth 客户端登记完成前不显示入口**；登记后按同一机制启用，并同步更新本政策。
- **敏感操作二次确认**：使用三方登录注册、没有密码的账号，在改资料、删除服务器数据、注销账号前，需用已绑定的来源重新授权一次，换取**一次性票据**（默认 300 秒有效）。票据只存在于页面内存，不写入本地存储、不上传；有密码账号走密码确认，不触发该流程。
- **加密文件夹（本机加密）**：用户可把文件夹迁入本地加密容器，使用 AES-256-GCM 加密、PBKDF2-SHA256（10 万轮）派生密钥；密码与恢复码只在输入时于内存中使用，**明文不存储、不上传**，容器密文只存本机。
- **新标签页（New Tab）仪表盘**：**完全在本地运行**，只读取本机已有的书签数据与访问统计，不上传任何内容。其搜索框在关键词既不是书签、也不是网址时，会将关键词转交**浏览器设置的默认搜索引擎**处理；本扩展不接收、不记录、不上传这些关键词。该功能随 Chromium 版（Chrome / Edge）提供。
- **设置页「检查更新」**：调用服务器公开接口 `GET /version`，只读取版本号与更新说明，不携带登录令牌、不上报任何本地数据。

本政策所称"个人数据"指可直接或间接识别个人身份的任何信息。本扩展在安装及使用过程中的数据处理行为均在本政策中充分披露，不存在隐藏的数据处理行为。

本政策主要针对 Microsoft Edge 浏览器编制；本扩展亦兼容其他基于 Chromium 内核的浏览器，相关政策原则上一致适用。本版 Edge 在扩展 ID 与独立 OAuth 客户端登记完成前不显示三方登录入口（`identity` 权限仅在入口显示时调用），其余数据处理行为与 Chrome 版一致。

## 1. 我们处理哪些数据

### 1.1 本地数据（仅存于用户设备，不离开浏览器）

| 数据类别 | 内容 | 存储位置 | 用途 |
|---|---|---|---|
| 书签数据 | 书签、文件夹及树结构 | 浏览器书签 API | 本扩展的核心数据，仅用于展示与管理 |
| 置顶状态 | 置顶书签 ID 集合 | `chrome.storage.local` | 呈现置顶分区 |
| 标签数据 | 标签定义及书签-标签关联 | `chrome.storage.local` | 标签管理与筛选 |
| 备注 | 用户为书签添加的备注文字 | `chrome.storage.local` | 备注展示 |
| 访问统计 | 书签访问频次、最近访问时间 | `chrome.storage.local` | 排序与检索；新标签页的常用网格与最近访问列表 |
| 回收站数据 | 已删除书签的元数据 | `chrome.storage.local` | 误删恢复、到期自动清空 |
| 设置偏好 | 主题、字号、语言、默认排序、新标签页「最近访问」显示开关、隐藏项等 | `chrome.storage.local` | 个性化界面 |
| 登录状态 | 服务器访问令牌（启用服务器功能后） | `chrome.storage.local` | 保持登录状态，登出即删除；首次设置密码后由服务器签发的新令牌覆盖旧令牌 |
| 加密文件夹元数据 | 容器标识、密钥派生参数（PBKDF2-SHA256、10 万轮）、salt、nonce、恢复码校验值、容器内条目 ID 映射 | `chrome.storage.local`（`bm_vault_*` 前缀） | 本机解锁、改密码、轮换恢复码与容器管理；**不含密码或恢复码明文** |
| 加密文件条目 | 经 AES-256-GCM 加密的书签内容与关联数据 | 浏览器 IndexedDB | 解锁后在内存中解密并展示；密文不出本机 |
| 备份文件（用户主动导出） | `.bbmk` 快照：书签树、标签、备注、文件夹颜色、置顶、访问统计、回收站元数据、加密容器密文与密钥派生参数 | 用户在本机选择的位置 | 由用户自行保管与迁移；导出**不需要解锁**，文件中不含密码 / 恢复码明文 |

以上数据全部存储在用户浏览器本地，本扩展开发者**无法访问**，也不会被上传至任何服务器。新标签页展示的问候、常用网格与最近访问列表均由上述**本地数据**渲染，没有独立的数据来源，也不读取浏览器历史记录。

加密文件夹的密码与恢复码仅用于在本机派生密钥：密码与恢复码明文既不写入扩展存储，也不写入 IndexedDB、不进入 `.bbmk` 导出文件、不上传服务器；解密得到的密钥仅存在于当前页面内存，页面关闭或手动锁定即释放。

### 1.2 服务器功能数据（需用户主动启用）

| 数据类别 | 内容 | 传输去向 | 用途 |
|---|---|---|---|
| 账号信息 | 用户名、密码（传输时加密）、登录令牌、邮箱（注册时填写） | 开发者运营的服务器 | 注册 / 登录 / 身份验证 |
| 三方登录标识 | 来源平台（GitHub / Google / X）、来源方用户 ID、来源方提供的邮箱（仅已验证时）、显示名、绑定时间 | 开发者运营的服务器（由服务器向来源方换取） | 三方登录、账号绑定与解绑；唯一键为「来源 + 来源方用户 ID」，**不按邮箱自动合并账号** |
| 敏感操作确认 | 操作用途（`update` / `deleteData` / `delete`）、回调地址、来源方授权码与 `state` | 开发者运营的服务器 | 校验身份后签发一次性票据；票据不是登录凭证、不签发登录令牌 |
| 反馈内容 | 反馈类型、文字内容、提交时间 | 开发者运营的服务器 | 接收用户意见与问题报告 |

> 提示：请勿在反馈内容中包含个人敏感信息（如身份证号、银行账号、密码等）。本版反馈功能不含附件上传。

> 说明：上表中的「三方登录标识」与「敏感操作确认」在 Edge 完成扩展 ID 与 OAuth 客户端登记、入口显示后适用；未登记前 Edge 版不会产生这两类数据。Chrome 版与完成登记的 Firefox 版均适用。

关于三方登录的补充说明：

- 本扩展只申请完成登录所必需的最小权限范围：GitHub `read:user user:email`、Google `openid email profile`、X `users.read`。
- 授权页由浏览器直接与来源方交互，本扩展不读取来源方的仓库、好友、时间线、私信等其他数据，也不收集头像。
- X 的 `users.read` 不返回邮箱，因此未绑定过的 X 身份不能单独建号，需先用邮箱注册后在设置中绑定。
- 三方登录入口按平台回调白名单显示。Edge 版在扩展 ID 与独立 OAuth 客户端登记完成前不显示入口，也不会发起三方授权请求；登记完成后，入口显示时通过 `identity` 权限打开授权窗口。

### 1.3 我们明确不收集

- 浏览历史、当前浏览的网页内容
- 姓名、电话、地址等个人身份信息（账号、邮箱信息除外，见 1.2）
- 位置信息、搜索记录（新标签页搜索框的关键词仅用于本次跳转，不落盘、不上传）
- 三方账号的好友列表、仓库、时间线、私信、头像等与登录无关的数据
- **健康、财务、支付等高度敏感信息**（此类信息与扩展功能无关，本扩展在任何情况下均不收集）
- 任何广告标识符或行为画像数据
- **任何非用户本人的个人信息**（本扩展不收集、也不向外部共享他人信息）
- 加密文件夹的密码、恢复码明文与派生密钥（仅在本机内存中使用）
- 敏感操作票据（仅页面内存暂存，用完即清）
- IP 地址：启用服务器功能后，服务器日志可能**短暂记录** IP 地址，**仅用于安全防护**（如异常登录检测），日志 30 日内删除；不使用服务器功能时不会产生此类记录。

## 2. 数据如何使用

- **本地数据**：仅用于在用户设备上呈现书签管理界面、实现管理功能，不用于任何其他目的。
- **服务器数据**：仅用于完成用户主动发起的身份验证、三方登录与账号绑定、敏感操作身份确认、问题反馈，不用于数据分析、营销或画像。
- **三方登录数据**：仅用于确认来源方身份、建立或关联本扩展账号、维护绑定关系；不用于任何其他目的。
- **一次性票据**：仅用于本次敏感操作的身份确认，校验通过后立即作废（服务端一次性消费）。
- **网络请求**：以下请求可能与外部发生
  - 链接校验 / 标题刷新：向用户指定的目标网站发送请求以检测可用性或获取标题；
  - 服务器功能：向开发者运营的服务器发送认证、账号管理或反馈请求；
  - 公告拉取：管理页加载时自动向服务器拉取产品公告（不含个人数据）；
  - 检查更新：设置页由用户主动触发，读取服务器公开的版本信息（不含个人数据、不携带登录令牌）；
  - 三方登录 / 敏感操作重新授权：由浏览器打开来源方授权页，仅携带最小 scope 与回调地址；
  - 默认搜索引擎跳转：新标签页搜索框的关键词既不是书签、也不是网址时，通过浏览器 search API 交由用户浏览器设置的默认搜索引擎处理。该请求由浏览器发起并遵循该搜索引擎的隐私政策，本扩展不接收、不存储、不上传这些关键词。
- 除按第 3 节期限对反馈内容作匿名化或删除处理外，本扩展不进行数据**聚合、画像**等二次加工；如未来功能确需此类处理，将遵循本政策与适用法律，并同步更新本政策。

## 3. 数据存储与传输

- **本地存储**：使用浏览器扩展存储（`chrome.storage.local`）与浏览器 IndexedDB，数据仅存在于用户设备，卸载扩展即全部删除（含加密容器）。
- **网络传输**：不在未经允许的情况下传输任何本地书签、标签、备注、访问统计或加密容器数据；网络传输采用 **HTTPS 等现代加密方法**，不使用不安全通道传输个人数据。
- **存储期限**：
  - 本地数据在用户主动清除或卸载前持续存在；
  - **账号数据**：注销申请提交后账号立即失效，账号资料、三方绑定标识与登录令牌记录在注销日起 **30 日内**删除；
  - **反馈内容**：创建后 **180 日内**匿名化或删除；保留的统计信息不含任何可识别字段；
  - **安全日志（含 IP 记录）**：写入后 **30 日内**删除；
  - **一次性票据**：默认 **300 秒**后失效，且使用一次即作废；
  - **登录令牌**：登出、账号注销或鉴权失败（401）时删除；首次设置密码后由服务器签发的新令牌覆盖旧令牌。
- **服务器所在地与跨境传输**：服务器由开发者运营，部署于**中国香港地区**。启用服务器功能时，相关数据传输将跨境进行。跨境传输的数据限于账号信息、反馈内容及安全日志（见 1.2、1.3），传输全程使用 HTTPS 加密，开发者采取合理的安全保障措施（如加密存储、最小权限访问控制）保护上述数据。**启用服务器功能即视为用户同意上述传输与处理。**

## 4. 第三方共享

除下述云服务托管外，本扩展**不向任何第三方共享、出售、出租或披露用户数据**，亦不从事任何形式的数据经纪（data brokering）活动。扩展内不含任何广告 SDK、统计 SDK 或第三方追踪代码。

### 4.1 三方身份提供方（GitHub / Google / X）

Edge 版在扩展 ID 与独立 OAuth 客户端登记完成前不显示三方登录入口，因此不会与 GitHub / Google / X 发生授权交互；登记完成并显示入口后，用户主动点击三方登录或"重新授权验证"时，浏览器会打开对应来源方的授权页，由用户在该页面确认授权范围。本扩展不会向来源方发送书签、标签、备注、访问统计、加密容器等任何本地数据；服务器仅使用来源方返回的最小身份信息（来源方用户 ID、已验证邮箱、显示名）完成登录或绑定。来源方对授权过程及账号数据的管理遵循其各自的隐私政策。

### 4.2 云服务提供商（受托处理者）

服务器以云服务器形式托管，云服务提供商仅作为受托处理者按开发者指令提供基础设施服务，不共享、不出售、不使用用户数据，其处理行为受本政策约束。

可能发生数据传输的仅有以下情形，均非"共享"给第三方服务商：

1. 用户与开发者运营的服务器交互（传输账号信息与反馈数据，由用户主动启用）；
2. 用户主动对目标网站发起的链接检测请求（仅返回链接可用状态与标题）。

## 5. 数据安全

- 本地数据保存在浏览器隔离的扩展存储空间与 IndexedDB 中，仅本扩展可读写；
- 登录令牌存储于本地扩展存储，登出、账号注销或 401 鉴权失败时自动清除；首次设置密码后旧令牌由服务端撤销；
- 加密文件夹使用 AES-256-GCM 加密条目、PBKDF2-SHA256（10 万轮）派生密钥，密码与恢复码各自包裹同一份随机数据密钥；密码与恢复码明文不落盘、不上传，解锁失败连续达到 3 次后进入 60 秒冷却；
- 敏感操作票据绑定"账号 + 会话 + 用途"，一次性消费、默认 300 秒失效，仅存在于页面内存，不写入本地存储（Edge 版账号均有密码，不产生票据）；
- 服务器数据采取加密存储与访问权限最小化控制，传输全程使用 HTTPS 加密；
- 三方登录的 `client_secret` 只保存在服务器环境变量中，不进入扩展包，也不写入客户端存储；
- 本扩展**不会公开披露**任何用户的认证信息；如发生涉及认证信息的安全事件，将及时通知受影响用户。

## 6. 用户权利与控制

> Edge 版在 OAuth 客户端登记完成前账号均为密码账号；登记后既支持密码账号，也支持纯三方账号，下表两类路径均适用。

| 操作 | 方式 | 效果 |
|---|---|---|
| 访问与查看信息 | 本地数据可在扩展界面中直接查看（书签、标签、备注、设置等）；服务器数据可通过登录账号在服务器侧访问 | 用户可随时了解本扩展处理的数据 |
| 更正与复制 | 通过设置页修改账号信息；需复制或更正数据的，通过联系方式提出，**7 个工作日内**响应 | 保障个人信息更正权、复制权 |
| 撤回同意 | 在设置页关闭服务器功能并登出，即停止后续传输与处理；服务器端已有数据可通过「删除我的服务器数据」删除 | 撤回后立即停止传输与处理 |
| 删除我的服务器数据 | 设置页"删除我的服务器数据"：有密码账号输入密码确认，纯三方账号用已绑定来源重新授权换票据确认 | 删除服务器端保存的反馈内容与附件；账号资料、登录状态与三方绑定关系保留（绑定关系可在「账号与登录」中逐项解绑） |
| 修改用户信息 | 设置页修改用户名 / 邮箱 / 密码（至少一项）：有密码账号输入当前密码，纯三方账号使用一次性票据；纯三方账号提交"票据 + 新密码"即为首次设置密码 | 修改即时生效；首次设置密码后旧登录令牌全部失效，需用新令牌继续 |
| 三方账号绑定 / 解绑 | 设置页"账号与登录"列出已绑定来源，逐项绑定或解绑（解绑需二次确认，且至少保留一种登录方式） | 绑定关系即时更新；解绑后该来源不能再用于登录或敏感操作确认 |
| 注销账号 | 登录页提供账号注销入口；有密码账号输入密码，纯三方账号使用一次性票据 | 账号立即失效，账号资料与三方绑定标识在 **30 日内**删除 |
| 清除全部本地数据 | 卸载扩展 | 本地数据（含设置、标签、备注、访问统计、加密容器、登录状态）全部删除 |
| 重置配置 | 设置页"重置配置" | 恢复默认设置 |
| 清除访问统计 | 设置页"清除访问次数" | 删除访问频次数据 |
| 清空回收站 | 设置页"清空回收站" | 彻底删除回收站内书签 |
| 关闭新标签页最近访问 | 设置页"显示最近访问"开关 | 新标签页不再展示最近访问列表（仅影响展示，不删除数据） |

## 7. 政策变更
