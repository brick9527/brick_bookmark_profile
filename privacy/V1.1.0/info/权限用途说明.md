# 权限用途说明

**适用于**：BrickBookmark（书签管理器浏览器扩展，下称"本扩展"）
**对应隐私政策版本**：v1.1.0（2026 年 11 月 27 日）
**说明**：本文件为隐私政策附件，独立说明本扩展所申请的各项浏览器权限及其用途，与隐私政策正文配套使用。

## Chromium 系浏览器（Chrome / Edge）

| 权限 | 用途 |
|---|---|
| `bookmarks` | 读写用户书签，实现书签管理的核心功能 |
| `storage` | 在本地保存置顶、标签、备注、设置、加密文件夹元数据等扩展数据 |
| `sidePanel` | 提供侧边栏界面，不离开当前页面即可访问书签 |
| `tabs` | 打开用户点击的书签链接（前台 / 后台） |
| `favicon` | 在书签列表中显示网站图标 |
| `search` | 仅用于新标签页搜索框：当关键词既不是书签、也不是网址时，转交浏览器设置的默认搜索引擎处理；本扩展不接收、不记录、不上传该关键词 |
| `identity` | 仅用于三方登录与敏感操作重新授权：通过浏览器授权窗口打开来源方授权页（GitHub / Google / X），本扩展只接收回调地址、把授权码交给服务器换取登录态或一次性票据；`client_secret` 只存服务器、不进扩展包。**Chrome 版与完成登记的 Edge 版均按服务器回调白名单显示入口并实际调用**；Edge 未登记扩展 ID 与独立客户端前不显示入口、不发起 `identity` 调用 |
| 与服务器通信（brick9527.qd.je） | 实现账号登录、注册、反馈提交、公告拉取、检查更新，以及三方登录 / 敏感操作确认的服务端交互（服务器地址由开发者打包配置） |
| 按需的网站访问权限（可选权限） | 仅用于用户主动触发的链接校验与标题刷新；作为可选权限，授予范围仅为用户实际校验 / 刷新的书签域名，由用户在首次使用对应功能时按需授予，授予前不访问任何网站，后台也不会自动访问任何网站。用户可在浏览器扩展详情页的"网站访问权限"中查看并随时取消任一已授权网站；链接校验页会显示已授权网站数量 |

本扩展仅申请实现上述功能所必需的权限，不申请任何超出功能需求的权限。

> Chromium 版另通过 manifest 的 `chrome_url_overrides.newtab` 用新标签页仪表盘替换默认新标签页；该字段属于页面替换声明，不涉及任何额外权限，仪表盘展示的数据全部来自本机已有的书签与访问统计。

## Firefox

| 权限 | 用途 |
|---|---|
| `bookmarks` | 读写用户书签，实现书签管理的核心功能 |
| `storage` | 在本地保存置顶、标签、备注、设置、加密文件夹元数据等扩展数据 |
| `tabs` | 打开用户点击的书签链接（前台 / 后台） |
| `identity` | 用于三方登录与敏感操作重新授权：通过 Firefox 授权窗口打开来源方授权页（GitHub / Google / X），本扩展只接收回调地址、把授权码交给服务器换取登录态或一次性票据；`client_secret` 只存服务器、不进扩展包。Firefox 回调主机由扩展 ID（`brickbookmark@brick9527.com`）的 SHA1 派生并已在服务端登记 |
| 与服务器通信（brick9527.qd.je） | 实现账号登录、注册、反馈提交、公告拉取与检查更新（服务器地址由开发者打包配置） |
| 按需的网站访问权限（可选权限） | 仅用于用户主动触发的链接校验与标题刷新；作为可选权限，授予范围仅为用户实际校验 / 刷新的书签域名，由用户在首次使用对应功能时按需授予，授予前不访问任何网站，后台也不会自动访问任何网站。用户可在浏览器扩展详情页的"网站访问权限"中查看并随时取消任一已授权网站；链接校验页会显示已授权网站数量 |

本扩展仅申请实现上述功能所必需的权限，不申请任何超出功能需求的权限。

> Firefox 的侧边栏由 `sidebar_action` 提供，不需要 `sidePanel` 权限；`favicon` 在 Firefox 无对应权限，站点图标由页面数据本地生成。

### Firefox 数据收集同意

Firefox 版依据浏览器内置的可选数据收集权限机制（`browser_specific_settings.gecko.data_collection_permissions.optional`，声明 `authenticationInfo` / `personallyIdentifyingInfo` / `technicalAndInteraction` 三类），在**登录、注册、三方登录、敏感操作重新授权、反馈提交前**通过 `browser.permissions.request({ data_collection: [...] })` 请求用户同意：

- 用户拒绝时立即中止本次操作，**不发送任何网络请求**；
- 同意范围仅限完成上述操作所必需的账号信息、身份验证信息与技术交互信息；
- 用户可随时在浏览器扩展权限设置中撤销该可选权限，撤销后再次操作会重新请求同意。

Firefox 版不打包新标签页仪表盘，因此**不声明 `search` 权限**，也不声明新标签页页面替换；三方登录通过 `identity` 权限在授权窗口完成（Firefox 回调已登记）。
